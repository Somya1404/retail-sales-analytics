# Retail Sales Analytics

Original portfolio project using Python, Pandas, SQL, Plotly, Scikit-learn, and Streamlit.

## Features
- Data cleaning and KPI analysis
- Monthly revenue trends
- Category, product, and regional analysis
- RFM-style customer segmentation
- Simple next-month revenue forecast
- Interactive Streamlit dashboard

## Dataset
The included dataset is synthetic and created specifically for this portfolio project. It contains 600 retail orders across 2025.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
